# Admin Authentication Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` or `executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Finish the deployment-managed single-administrator login flow so all interview-management pages and mutations require a valid session or explicit admin API key, browser mutations enforce CSRF, and sessions expire by inactivity.

**Architecture:** Keep `adminAuth` as the authorization boundary and add one conditional mutation guard that authenticates first, bypasses CSRF only for a successfully validated `X-Admin-Key`, and otherwise invokes Fastify CSRF protection. Render request tokens generated by `reply.generateCsrf()` into the login page and admin shell; remove non-durable application-managed password changes.

**Tech Stack:** TypeScript 5.9, Fastify 5, `@fastify/secure-session`, `@fastify/csrf-protection`, Nunjucks, HTMX, Vitest 4, Playwright 1.61, Biome.

**Design:** `docs/superpowers/specs/2026-08-19-admin-auth-completion-design.md`

**Scope guard:** Never edit, stage, restore, or commit `VERSION` or `reports/*.xlsx` as part of this work.
