# 演示环境手册

> 作品：深访者（dialog-survey）· 队伍：破砂锅
> 本手册覆盖三种演示部署方式、完整演示剧本与排障指南。所有命令均经过仓库配置核对。

---

## 一、三种演示方式一览

| 方式 | 适用场景 | 依赖 | 耗时 |
|------|---------|------|------|
| **A. 本地源码模式** | 评委复现、开发调试（推荐） | Node.js 20+ / PostgreSQL 16 | ~10 分钟 |
| **B. Docker Compose** | 一键启动完整体验 | Docker Desktop | ~5 分钟 |
| **C. npx 安装器** | 真实部署形态演示 | Node.js 20+ / PostgreSQL | ~5 分钟 |

> 三种方式的对话演示环节均需钉钉企业应用凭证（真实对话依赖钉钉 Stream 长连接）；
> **没有钉钉凭证也可以完整演示系统启动、管理界面、模板/计划管理、报告查看与 PDF/Excel 导出**（详见第七章"演示边界"）。

---

## 二、环境要求

| 组件 | 要求 | 说明 |
|------|------|------|
| Node.js | >= 20.19.0 | 项目使用 `tsx --env-file` 特性 |
| PostgreSQL | 16（14+ 可用） | Docker 方式无需本机安装 |
| 钉钉 | 企业内部应用（可选） | Stream 模式，**无需公网 IP** |
| LLM | OpenAI 兼容接口（可选） | 云端 API 或本地 Ollama 均可 |
| Docker | 可选 | 方式 B 需要 |

## 三、方式 A：本地源码模式（推荐）

### 步骤 1 · 获取代码

```powershell
# 代码仓库（云雀研发云，参赛专属）
git clone https://git-nj.iwhalecloud.com/codecompetition8md-psg/dialog-survey.git
cd dialog-survey
npm install
```

> 也可直接安装 npm 公开发布的正式版：`npx dialog-survey install`（npm 包名 `dialog-survey`）。
> 全部依赖为纯 JS/TS 包，无原生模块编译步骤，Windows/macOS/Linux 通用。

### 步骤 2 · 准备数据库

任选其一：

```powershell
# 已有 PostgreSQL：创建数据库即可
createdb dialog_survey

# 或使用 Docker 只需一个容器
docker run -d --name dialog-survey-db `
  -e POSTGRES_USER=dialog_survey `
  -e POSTGRES_PASSWORD=dialog_survey_secret `
  -e POSTGRES_DB=dialog_survey `
  -p 5432:5432 postgres:16-alpine
```

### 步骤 3 · 配置环境变量

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，最少需要配置以下项目（其余可留空）：

```ini
NODE_ENV=development
PORT=3001
DATABASE_URL="postgresql://dialog_survey:dialog_survey_secret@localhost:5432/dialog_survey?schema=public"  # pragma: allowlist secret

# LLM（OpenAI 兼容；接本地 Ollama 示例）
LLM_API_KEY=your-llm-api-key
LLM_MODEL=qwen2.5
# LLM_BASE_URL=http://localhost:11434/v1/chat/completions

# 钉钉（无凭证可留空——服务仍可启动，仅真实对话不可用）
DINGTALK_CLIENT_ID=your-dingtalk-client-id
DINGTALK_CLIENT_SECRET=your-dingtalk-client-secret
DINGTALK_AGENT_ID=your-dingtalk-agent-id

# 管理后台登录（必配，否则无法登录 Admin UI）
ADMIN_USERNAME=admin
ADMIN_PASSWORD_HASH=<用下方命令生成>
SESSION_SECRET=<用下方命令生成>
SESSION_SALT=<用下方命令生成>
```

生成密码哈希与密钥（复制输出到 `.env`）：

```powershell
# 管理员密码哈希（把 your-password 换成你的密码）
node -e "const bcrypt=require('bcryptjs');bcrypt.hash('your-password',12).then(console.log)"

# SESSION_SECRET（32 字节）
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# SESSION_SALT（16 字节）
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
```

### 步骤 4 · 初始化数据库

```powershell
npx prisma generate   # 生成 Prisma Client
npx prisma db push    # 同步表结构
```

### 步骤 5 · 灌入演示数据（可选，推荐）

```powershell
# ① 导入「研发线内部质量满意度调查」演示模板
#    含 9 个问题 + 6 个结构化维度（交付物质量/上游质量/质量趋势/结果指标/改进方向/建议）
npx tsx prisma/seed-satisfaction-survey.ts
```

### 步骤 6 · 启动服务与健康检查

```powershell
npm run dev           # tsx 热重载启动，监听 3001

# 另开窗口验证
curl http://localhost:3001/health
```

### 步骤 7 · 打开管理后台

浏览器访问 `http://localhost:3001/admin/login`，使用 `.env` 中配置的管理员账号登录。

## 四、方式 B：Docker Compose 一键启动

```powershell
# 准备 .env（同方式 A 步骤 3，DATABASE_URL 会被 compose 覆盖为容器内地址）
Copy-Item .env.example .env

docker compose up -d --build
docker compose ps                 # 两个容器 healthy 即为就绪
curl http://localhost:3001/health
```

- 容器编排：`dialog-survey-db`（PostgreSQL 16）+ `dialog-survey-app`（应用，含健康检查）；
- 数据持久化：`postgres_data` 卷，重启不丢数据；
- 管理后台：`http://localhost:3001/admin/login`。

> 灌入演示数据：可在 Admin UI 手动创建模板，或在本机源码模式下执行 seed（见方式 A 步骤 5）。

## 五、方式 C：npx 安装器（真实部署形态）

```powershell
# 交互式安装（逐项提示输入配置）
npx dialog-survey install

# 或非交互式（一行命令完成全部配置）
npx dialog-survey install `
  --db-url "postgresql://<user>:<password>@localhost:5432/dialog_survey" `
  --llm-api-key "sk-xxx" `
  --dingtalk-client-id "xxx" `
  --dingtalk-client-secret "xxx" `
  --dingtalk-agent-id "xxx"
```

安装器自动完成：环境检查（Node 版本 / PG 连通性 / 端口占用）→ 生成配置（密钥与管理员密码哈希自动生成，**明文密码只显示一次**）→ 依赖安装 → Prisma 初始化 → 平台化启动（Linux/macOS 走 PM2，Windows 自动切换直连模式）→ 健康检查。

后续管理命令：

```powershell
npx dialog-survey status    # 查看服务状态
npx dialog-survey stop      # 停止服务
npx dialog-survey start     # 启动服务
npx dialog-survey uninstall # 卸载
```

## 六、演示剧本（约 5 分钟）

> 适配"视频录制"与"现场答辩"两种场合。时间分配可按需裁剪。

### 第 1 幕 · 系统就绪（30 秒）

1. 展示 `curl http://localhost:3001/health` 返回健康状态；
2. 浏览器打开 Admin UI 登录页，完成登录。

**旁白**：一个健康检查、一次登录，整个系统跑在本地环境——不需要公网 IP，不需要回调服务器。

### 第 2 幕 · 模板与维度（45 秒）

进入「模板管理」：

1. 展示 seed 导入的「研发线内部质量满意度调查」模板；
2. 打开模板详情，展示 **9 个话题问题** 与 **6 个结构化维度**（交付物质量 / 上游质量 / 质量趋势 / 结果指标 / 改进方向 / 建议）；
3. 展示维度 JSON 的配置形态。

**旁白**：换个调研场景，不需要改代码——换模板、换维度即可。

### 第 3 幕 · 真实对话（2 分钟，核心场面）

> 在钉钉侧录屏或现场演示。此前预置了测试访谈（PENDING 状态）。

1. 在钉钉中向机器人发送任意一条消息，访谈开始——机器人发来**邀请语**（说明异步机制：不需要立即回复）；
2. 回答第一个问题：机器人**肯定回答内容 → 追问细节**（观察追问质量：追问具体场景、亲身经历）；
3. 故意给出**敷衍回答**（如"还行吧"）：机器人切换策略，换角度激发兴趣继续追问；
4. 观察追问**最多 5 轮**后自动推进下一题（追问上限护栏）；
5. 发送"我想结束了"：机器人确认结束并致谢；
6. 稍候片刻，报告自动生成（分析实时触发）。

**旁白**：注意三件事——① 机器人每次只问一个问题；② 它会根据你的回答决定追问还是推进；③ 无论你怎么回答，对话一定会在有限轮次内收敛——这是"LLM 建议 + 规则引擎兜底"的双层设计。

### 第 4 幕 · 报告与导出（1 分钟）

1. 进入「报告」查看刚才访谈的分析报告：关键发现（附原话引用）、情感分析、行动建议；
2. 展示维度标注结果：每个维度的情感倾向与引用原文（已做 PII 匿名化）；
3. 导出 **PDF**（A4 排版）与 **Excel**（问答 + 报告多 Sheet），当场打开文件展示。

### 第 5 幕 · 批量洞察（30 秒，按需）

1. 进入批量聚合页面，展示多份访谈的主题聚类结果（3-8 个子主题 + Top 5 涌现议题）；
2. 展示维度统计（提及率 + 情感分布）。

**结尾旁白**：从一次深访到一批洞察，从对话到 PDF 报告——这就是"比问卷更深，比人工访谈更广"。

## 七、演示边界（无钉钉/LLM 凭证时）

| 能力 | 无钉钉凭证 | 无 LLM 凭证 | 说明 |
|------|:---:|:---:|------|
| 服务启动 + 健康检查 + Admin UI | ✅ | ✅ | 完全可演示 |
| 模板/计划/成员管理 | ✅ | ✅ | 完全可演示 |
| 报告查看 + PDF/Excel 导出 | ✅ | ✅ | 使用已有报告数据 |
| 真实钉钉对话 | ❌ | ❌ | 需钉钉凭证 |
| 新访谈的自动分析 | — | ❌ | 需 LLM 凭证（对话结束后自动触发） |

> 提示：服务在未配置钉钉凭证时仍可正常启动（设计如此，便于本地开发与展示）。

## 八、常见问题排查

| 现象 | 原因 | 处理 |
|------|------|------|
| `PrismaClientInitializationError` | PostgreSQL 未启动或 `DATABASE_URL` 错误 | 确认数据库运行、连接串正确 |
| 端口 3001 被占用 | 旧的 dev 进程未退出（`tsx --watch` 常留孤儿进程） | Windows：`netstat -ano \| findstr 3001` 后结束进程；Linux/macOS：`fuser -k 3001/tcp` |
| Admin UI 登录失败 | 未配置 `ADMIN_PASSWORD_HASH` / `SESSION_SECRET` / `SESSION_SALT` | 按方式 A 步骤 3 生成并补齐 |
| PDF 导出报浏览器错误 | Playwright Chromium 未安装 | `npx playwright install chromium`，或在 `.env` 设置 `PLAYWRIGHT_EXECUTABLE_PATH` |
| 对话无响应 | 钉钉凭证/LLM 配置缺失 | 检查 `.env` 中对应配置；服务日志会给出具体原因 |
| 集成测试失败 | 首次运行需初始化 PGlite 模板缓存；E2E 用例需要 Chromium | 测试默认使用内嵌 PGlite，无需本地 PostgreSQL；E2E 先执行 `npx playwright install chromium` |
