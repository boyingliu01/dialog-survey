## 四、提交操作说明

### 4.1 提交渠道

按活动规程，材料提交至**云雀研发云文档库**（具体入口以活动组通知为准）。建议上传顺序：

```
第一步：陈述文档          （评审核心阅读材料）
第二步：核心代码清单      （配合源码查阅）
第三步：演示手册          （评委复现用）
第四步：视频成片          （依 04 脚本录制后上传）
第五步：代码/运行入口说明 （第三章表格内容，可并入陈述文档或单独一页）
```

### 4.2 Markdown → 提交格式建议

本材料包为 Markdown 格式，如提交系统要求 Word/PDF：

| 方式 | 操作 |
|------|------|
| 云雀文档库支持导入 | 直接导入 `.md` 文件（优先尝试） |
| 转 Word/PDF | Typora / VS Code Markdown 插件 / pandoc：`pandoc 01-陈述文档.md -o 01-陈述文档.docx` |
| 在线粘贴 | 将 Markdown 内容粘贴到云雀在线文档，表格会自动识别 |

> 提示：`01-陈述文档.md` 中的目录锚点与表格在转换后可能需微调，转好后建议通读一遍。

### 4.3 视频录制

1. 按《03-演示手册》完成环境部署与数据准备；
2. 按《04-视频简介脚本.md》的"录制准备清单"逐项打勾；
3. 按分镜脚本与口播全文录制，时间轴速查表可直接用于剪辑打板；
4. 成片建议：1080p / 全程硬字幕 / ≤4 分钟。

### 4.4 提交前检查清单

- [ ] 五份文档已按 4.2 转换为目标格式并通读
- [ ] 陈述文档中所有数字可在仓库复验（见其第八章"可验证事实清单"）
- [ ] 视频成片已导出并本地播放验证
- [ ] 提交内容中不含任何真实密钥、手机号等敏感信息
- [ ] 提交页所需的队伍/作品信息与本文第二章一致
- [ ] 留意活动通知的截止时间（材料准备期至 10 月下旬，以活动组通知为准）
